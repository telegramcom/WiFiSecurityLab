# Security and Misuse Concerns

## Scope

WiFiSecurityLab~ is an educational Android application intended for authorized, controlled laboratory exercises. It is not a production network-security product and must not be used to capture real credentials, intercept traffic, impersonate a network, or access systems without permission.

The project is deliberately designed to redact passwords as `[REDACTED — SIMULATION]` and to keep its demonstration server local to the lab device.

## Reporting a security issue

If you discover a software vulnerability, accidental credential handling, or a way the project could be misused, please do not publish working exploit details immediately. Open a private security report to the repository maintainers through GitHub, including:

1. A clear description of the issue.
2. The affected version or commit.
3. Reproduction steps using synthetic data only.
4. The potential impact and a suggested mitigation.

Never include real passwords, API keys, personal data, or traffic captures in a report.

## Responsible use

Use the app only on devices and networks you own or are explicitly authorized to test. Stop the exercise immediately if real user data appears, and report the issue to the maintainers.
